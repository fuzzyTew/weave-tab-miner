          What is real here

          Tested against mainnet
          • Replaying block 2,040,257 with real RandomX finds its own solution again: the same nonce and hash.
          • Packing that block's unpacked chunks reproduces its packed sub-chunks exactly.
          • The VDF recomputes step 119,924,183 to the block's output.
          • Transactions match arweave-js, which verifies transactions signed here.
          Not yet tested live
          • Requests to gateways, peers and VDF servers: written from the node source, but the machine this was built on could not reach Arweave.
          • A found solution is not yet built into a signed block and sent.
          • If the 512 MiB RandomX cache cannot be allocated, the page falls back to SHA-256 stand-ins and says so.
